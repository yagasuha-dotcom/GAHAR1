# CLINT TRADE V2

A fictional financial-market simulation game. It is not connected to real brokers, real money, or real trading accounts.

## Features
- Forex, crypto, stocks, commodities and indices
- Deterministic living market engine
- Regimes: sideways, bull, euphoria, distribution, bear, panic, recovery
- OHLC candlestick chart without external chart-library API issues
- News events that influence selected assets
- Long/short positions, leverage, margin and P/L
- Portfolio, orders, journal, missions, bank and analytics pages
- LocalStorage save + reset
- Responsive mobile terminal UI

## Run
npm install
npm run dev

## Build
npm run build
